## Publish with GitHub Pages

1. Create a GitHub repository, for example `bichi-website`.
2. Extract this ZIP and upload all files and folders to the repository root. `index.html` must be at the root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/bichi-website/`.
7. Open the URL on mobile and desktop and test every footer link.
